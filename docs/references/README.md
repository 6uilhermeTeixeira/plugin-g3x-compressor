## Fatos documentados relevantes

- Threshold: -60 a 0 dBFS; Ratio: 0.5 a 50, incluindo expansão.
- Attack: 0.5–500 ms; Release: 5–5000 ms.
- Soft knee começa a agir aproximadamente 6 dB abaixo do threshold.
- Release Manual ou ARC; comportamentos Electro e Opto.
- Caráter Smooth ou Warm; Warm adiciona harmônicos graves com compressão.
- Mix dry/wet, gain change bipolar, limiter integrado e Trim pós-limiter.
